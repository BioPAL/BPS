ACT I - CI/CD
CI/CD pipeline design
Three-tier system. Each proposed change is classified automatically based on what it touches. The base branch determines which checks run.
Baseline
Lint, licence headers, SPDX check, unit tests
Trigger: Every push and pull request
Maximum duration: 5 min
Extended
Integration tests, build verification, doc generation
Trigger: Pull requests to shared branch
Maximum duration: 20 min
Heavy
Full processing chain, regression tests, performance
Trigger: Nightly or on-demand
Maximum duration: 2 hours
tier-policy.yml defines the classification rules. Auto-classification from changed file paths.
