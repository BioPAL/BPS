# Science Guide

The authoritative scientific references for BIOMASS BPS are the **ATBDs**
and **Product Format Documents** published as PDFs on the ESA dissemination
portal.

For the full document catalog (L1, L2 AGB, FH, FD, ICD, IODD, and more), see
[About → Applicable documents](../about/applicable-documents.md).

:::{admonition} Web ATBD conversions
:class: note

Selected ATBDs are published as searchable web pages, one folder per product.
Each folder has its own landing page, chapter navigation, and PDF export.
Web versions are **drafts** until Aresys and ESA approve them; the official PDF
remains authoritative until then.
:::
