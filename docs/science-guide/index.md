# Science Guide

The scientific references for BIOMASS BPS are the **Algorithm Theoretical
Baseline Documents (ATBDs)** and the **Product Format Documents (PFDs)**
approved by Aresys and ESA.

For the full document catalogue (L1, L2 AGB, FH, FD, ICD, IODD, and more), see
[About → Applicable documents](../about/applicable-documents.md).

:::{admonition} Web versions of the ATBDs and PFDs
:class: note

Selected ATBDs and PFDs are published as searchable web pages, one folder per
document. Each folder has its own landing page, chapter navigation, and a PDF
export of the web pages.

The box "Authoritative document" at the top of each landing page gives the
reference, issue and date of the approved document that the web version
renders. The approved document remains the reference.

- L1 Stack, L2 AGB, L2 FD and L2 FH ATBDs: the box links to the official PDF on
  the ESA dissemination portal (BPS v4.4.2 documents).
- L1 SAR ATBD and the four PFDs, reissued for BPS 4.5.0: their official PDF is
  not online yet, and the box has no link.

The PDF export is printed from the web pages: it is not the approved document.
:::

The drawings of these pages are editable text sources: see
[Editing the figures](editing-figures.md).
