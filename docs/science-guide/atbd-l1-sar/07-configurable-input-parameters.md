# 7. Configurable Input Parameters

A comprehensive list of configurable input parameters for the different L1 Processor modules can be found in the BPS Auxiliary Products Format document {rd}`25` and in particular in the Auxiliary L1 Processing Parameters product (`AUX_PP1___`).

In each section of this document, for each processing step, the most relevant processing parameters are indicated as part of each step inputs.
