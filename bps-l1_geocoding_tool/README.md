# Biomass L1 geocoding tool package

`bps_l1_geocoding_tool` is a command-line interface (CLI) tool designed to geocode Biomass Level 1a/b/c data.

The tool starts from an input BIOMASS L1S product (L1a, L1b or L1c), plus DEM database, and generates an output geocoded L1 product in NetCDF format.

The structure of a sample NetCDF file generated by this tool is the following. Notes have been added to describe content of each section.
In brief, the geocoded product contains:

- geocoded SAR L1 data, divided per polarization, with the corresponding latitude and longitude metadata
- platform data (satellite position and velocity)
- main product metadata

```none
netcdf BIO_S2_SCS__1S_20260202T142654_20260202T142715_T_G01_M01_CDR_T024_F133_01_DSW1IL {
types:
  compound fcomplex {
    float real ;
    float imag ;
  }; // fcomplex

// global attributes:
                :description = "BIOMASS Geocoded L1 Product" ;
                :product_name = "BIO_S2_SCS__1S_20260202T142654_20260202T142715_T_G01_M01_CDR_T024_F133_01_DSW1IL" ;
                :mission = "BIOMASS" ;
                :product_type = "GEC" ;
                :swath = "S2" ;
                :file_originator = "ARESYS" ;
                :file_origination_date = "2026-07-26T11:17:34.028725" ;
                :nodata_value = -9999.f ;
                :reference_azimuth_time = "2026-02-02T14:23:58.937500" ;

group: sar_data {
  // this group contains the geocoded SAR L1 data, divided per polarization, with the corresponding latitude and longitude metadata
  // data are expressed as 2D arrays in the latitude/longitude time domain

  // group attributes:
                :description = "SAR data" ;

  group: HH {
    dimensions:
        latitude = 1653 ;
        longitude = 1175 ;
    variables:
        float latitude(latitude) ;
                latitude:units = "deg" ;
        float longitude(longitude) ;
                longitude:units = "deg" ;
        fcomplex data(latitude, longitude) ;

    // group attributes:
                :description = "SAR data (H/H polarization)" ;
    } // group HH

  group: HV {
    dimensions:
        latitude = 1653 ;
        longitude = 1175 ;
    variables:
        float latitude(latitude) ;
                latitude:units = "deg" ;
        float longitude(longitude) ;
                longitude:units = "deg" ;
        fcomplex data(latitude, longitude) ;

    // group attributes:
                :description = "SAR data (H/V polarization)" ;
    } // group HV

  group: VH {
    dimensions:
        latitude = 1653 ;
        longitude = 1175 ;
    variables:
        float latitude(latitude) ;
                latitude:units = "deg" ;
        float longitude(longitude) ;
                longitude:units = "deg" ;
        fcomplex data(latitude, longitude) ;

    // group attributes:
                :description = "SAR data (V/H polarization)" ;
    } // group VH

  group: VV {
    dimensions:
        latitude = 1653 ;
        longitude = 1175 ;
    variables:
        float latitude(latitude) ;
                latitude:units = "deg" ;
        float longitude(longitude) ;
                longitude:units = "deg" ;
        fcomplex data(latitude, longitude) ;

    // group attributes:
                :description = "SAR data (V/V polarization)" ;
    } // group VV
  } // group sar_data

group: platform_data {
  // this group contains the platform data (satellite position and velocity)
  // data are expressed as 2D arrays in the coordinate/azimuth time domain (coordinate are X,Y,Z)
  // note that azimuth times are provided as relative ones (i.e. float values) with respect to reference_azimuth_time global attribute (which is an absolute time in ISO 8601 datetime format)

  dimensions:
        azimuth_time = 397 ;
        state_vector_number = 3 ;
  variables:
        float azimuth_time(azimuth_time) ;
                azimuth_time:units = "s" ;
        float position(azimuth_time, state_vector_number) ;
                position:units = "m" ;
        float velocity(azimuth_time, state_vector_number) ;
                velocity:units = "m/s" ;

  // group attributes:
                :description = "Platform data" ;
  } // group platform_data
}
```

## Installation

In order to install this tool, a Python environment shall be created and activated:

```bash
conda create --name my-env-name python=3.12
conda activate my-env-name
```

Then this package can be installed using ``conda``:

```bash
conda install biomass-bps::bps-l1_geocoding_tool
```

## Command Line Usage

The tool help can be displayed with the following command line:

```bash
bps_l1_geocoding_tool --help
```

The tool can be executed with the following command line:

```bash
bps_l1_geocoding_tool --l1 <path to input L1S product (L1a, L1b or L1c)>
                      --dem <path to DEM database>
                      --latlonstep <output product latitude and longitude sampling step [deg]>
                      --out <path to output folder>
```

Here below an example:

```bash
bps_l1_geocoding_tool --l1 /path/to/BIO_S2_SCS__1S_20260202T142654_20260202T142715_T_G01_M01_CDR_T024_F133_01_DSW1IL
                      --dem /path/to/DEM
                      --latlonstep 0.0005
                      --out /path/to/l1_geocoding_tool_output_folder
```

All the inputs are mandatory.

At the beginning of the processing the existance of all the inputs is checked (then also the output folder shall exist).

The output product (NetCDF file) and all the intermediate data are written in this folder. Before exiting, the processor automatically removes all the intermediate data.

The output product is a single NetCDF file with the same name of input L1S product and with .nc extension.
